# packages

## Overview

Monorepo workspace packages comprising the TemplateGoblin engine, visual builder, shared type definitions, and marketing/documentation website.

## Subdirectories & Boundaries

- [core](./core/README.md): High-scale Node.js PDF template rendering engine with zero UI dependencies.
- [site](./site/README.md): Vite and React marketing website, documentation center, and showcase deployed to GitHub Pages.
- [types](./types/README.md): Canonical TypeScript type definitions, template schemas, and input data contracts.
- [ui](./ui/README.md): Interactive visual template builder, canvas editor, and standalone local server.
